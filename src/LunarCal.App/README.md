# LunarCal.App

WPF shell (MVVM, CommunityToolkit.Mvvm) hosted by Microsoft.Extensions.Hosting. Output: `LunarCal.exe`.

| Folder | Contents |
| --- | --- |
| `Views/` | Windows, pages, dialogs |
| `ViewModels/` | View models |
| `Controls/` | Custom controls (month grid, mini-calendar, AI command bar) |
| `Resources/` | Themes, styles, icons |
| `Localization/` | `Strings.vi-VN.resx`, `Strings.en-US.resx` (FR-I18N, Phase 2) |

`appsettings.json` holds **non-secret** defaults only (spec §11).
